# King Data Driven Decision source assets

The sample workbook, oil-painted steel/gold knights, clip manifest and battlefield come from Steven Kauwe's
existing `king-ddd-arena` project. The original README documents the ShapeStage rigs and per-frame oil-painting
pipeline. This integration reuses those exact assets; it does not replace them with third-party game sprites.
CrabScape's all-rights-reserved policy applies to the original game artwork and this sample.

## UI fonts

egui 0.36.2 embeds Hack Regular, Noto Emoji, Ubuntu Light and emoji-icon-font. These retain their own
licenses, not CrabScape's artwork terms. The original license texts are shipped in `font-licenses/`:
Hack/Bitstream Vera notices, SIL Open Font License 1.1, Ubuntu Font Licence 1.0 and the emoji-icon-font
MIT notice. Source: the `epaint_default_fonts` 0.36.2 crate and its upstream font projects.
